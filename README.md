# 0817 数据集标注预览

在线看标注结果，不用下载数据、不用装软件，浏览器打开就行：

**https://goose666666.github.io/0817-detection-preview/**

## 里面有什么

1200 张图，19 个类别，23 个拍摄序列，按 CA 日用品、CB 副食品、CC 饮料、CD 水果四个文件夹分开。
首页列出每个序列的图片数和框数，以及每个类别的图片数和实例数。点序列名进去看图。

看图页面里，左右方向键翻页，底部缩略图条可以直接跳到某一张，右侧点类别名可以只显示这一类的框，
顶上两个按钮分别关掉框和框上的类别名。

## 和交付包的关系

页面上画的框就是交付的 YOLO 标注，类别号与 `classes.txt` 一致，编号含义按甲方规范文件，
CD001 是桃子、CD002 是苹果。

预览图为了加载快缩到了长边 1000 像素，框按比例画，所以看位置准、看细节请用交付包里的原图。
交付包里的图片和标注是全分辨率的原始文件。

## 目录

```
index.html        首页，序列清单与类别统计
view.html         看图页面
data/*.json       每个序列的框，坐标已归一化到 0 到 1
img/<文件夹>/     预览图，长边 1000 像素
th/<文件夹>/      缩略图，长边 160 像素
```
